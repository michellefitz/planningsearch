Option C

One object

Stop having two things. The agent's reasons attach to the record itself, so a cited property is a single block: what it was, what happened, and why — with the reasons as the card's own content.

As rendered

The reasons are the card's body, not a paragraph beside it.

⚑Biggest build. The token becomes a structure, not a marker — the model has to emit reasons attached to an id, and the renderer has to parse them. It also puts the model's words inside something that looks like a record, which is the one place a mistake reads as fact.
Why

Nothing is duplicated because there is only one thing. Reasons become comparable across properties — three cards, same shape, easy to see the pattern the answer is claiming.

Tradeoff

Constrains what the agent can say: not every mention is a tidy three-bullet refusal. Needs a fallback to a plain card whenever the shape does not fit, which is most casual mentions.
